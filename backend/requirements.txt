# Core application dependencies -- everything needed to boot the app
# and run the full document pipeline with the "stub" OCR engine.
#
# Deliberately does NOT include PaddleOCR, EasyOCR, PaddlePaddle, or
# torch: those are imported lazily inside app/ocr/paddle_engine.py and
# app/ocr/easyocr_engine.py (never at module scope -- verified via AST
# parse of every file in app/), so the application boots and the
# entire pipeline runs correctly without them installed at all, as
# long as OCR_DEFAULT_ENGINE=stub (the default). Verified: all 190
# backend tests pass using ONLY this file's packages, including the
# test that specifically checks PaddleOCR fails gracefully (422, not a
# 500 or an import crash) when genuinely not installed.
#
# Install requirements-ocr.txt as well if you need real OCR (PaddleOCR
# or EasyOCR) rather than placeholder stub output -- see that file and
# requirements-ocr-torch-notes.txt for why torch needs special handling.
