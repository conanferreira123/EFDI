# Optional OCR engines: PaddleOCR and EasyOCR.
#
# Install this ON TOP OF requirements.txt (not instead of it) when you
# want real text recognition instead of the "stub" engine's placeholder
# output:
#
#   pip install -r requirements.txt
#   pip install -r requirements-ocr.txt
#
# Then set OCR_DEFAULT_ENGINE=paddleocr or =easyocr in .env (or pass
# {"engine": "paddleocr"} per-request to POST /ocr/documents/{id}/run).
#
# IMPORTANT -- EasyOCR additionally requires PyTorch, which is NOT
# listed here on purpose. See requirements-ocr-torch-notes.txt: the
# correct torch wheel depends on whether you have an NVIDIA GPU, and
# the CPU-only build is not on PyPI, so it needs its own pip command
# with a different --index-url.
#
# IMPORTANT -- PaddleOCR downloads model weights on first use from
# Baidu BOS / HuggingFace / ModelScope / AIStudio. If none of those
# hosts are reachable from your deployment network, PaddleOCR will
# raise a clear error at first use (handled gracefully -- see
# app/ocr/paddle_engine.py and the test
# test_run_ocr_with_paddleocr_fails_gracefully_not_with_500) rather
# than crashing the app. Pre-download weights and point at a local
# model dir if your deployment has no internet egress; see PaddleOCR's
# own docs for the relevant constructor arguments.
